# Papers

Put PDF copies of your papers here, e.g. `li-2026-genetic-diversity.pdf`.
Link them from the `publications` list in index.html:

    links: { PDF: "papers/li-2026-genetic-diversity.pdf", DOI: "https://doi.org/..." }

Only post versions you're allowed to share (usually your accepted manuscript).
Check each journal's policy at https://openpolicyfinder.jisc.ac.uk/
